# 知识收集 (Knowledge Collection)

把零散的学习问答（Q&A）沉淀为结构化、可检索的知识库。知识库位于仓库根目录的 `knowledge/`，
全部为纯 Markdown 文件。

## 何时使用

- 用户给出一个问题与答案，希望记录下来
- 用户分享了一个知识点 / 结论 / 踩坑经验
- 用户要求整理、归类、检索已有知识
- 一个分类下条目过多，需要细分

## 核心工作流

1. **读索引**：先读 `knowledge/INDEX.md`，了解现有分类与对应文件路径。
2. **定位分类**：判断本条 Q&A 属于哪个已有分类。
   - 找到合适分类 → 追加到该分类文件。
   - 没有合适分类 → 新建分类文件，并在 `INDEX.md` 登记。
3. **写入**：按格式追加 Q&A（格式见 `references/format.md`）。
4. **判断是否细分**：写入后若该分类文件条目过多，触发细分流程
   （阈值与方法见 `references/categorization.md`）。
5. **更新索引**：任何新增分类 / 细分 / 新文件，都要同步更新 `knowledge/INDEX.md`。

## 渐进式加载（按需读取）

本 SKILL.md 是入口，保持精简。按需读取以下引用文件，不要一次性全部加载：

- 分类规则、细分阈值与拆分方法 → 读 `references/categorization.md`
- Q&A 条目的 Markdown 格式规范 → 读 `references/format.md`
- 现有分类与文件位置 → 读 `knowledge/INDEX.md`

当某个分类增长出独立的子文件后，这些子文件同样按需加载：路由时只读 `INDEX.md` 与
目标分类的索引，不读无关分类的内容。

## 约束

- 只在**本仓库**的 `knowledge/` 下进行知识收集操作。
- 全部使用纯 `.md` 文件，不引入数据库或其他格式。
- 每次写入后保持 `INDEX.md` 与实际文件结构一致。
