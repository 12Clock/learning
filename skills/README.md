# Skills

本仓库的技能（skill）目录。

## knowledge-collection（知识收集）

把学习中的问答（Q&A）沉淀为结构化、可检索的知识库，存放于仓库根目录的 `knowledge/`。

- 入口：[`knowledge-collection/SKILL.md`](./knowledge-collection/SKILL.md)
- 采用渐进式加载：SKILL.md 精简，详细规则按需引用 `knowledge-collection/references/` 下的文件。
- 能力：对 Q&A 分类，并在某一类过多时进一步细分类；全部为纯 Markdown。

详见仓库根目录的 `AGENTS.md`。
